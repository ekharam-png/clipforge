Connect Claude to ClipForge

After this, you can ask Claude in plain words to edit your ClipForge videos on your computer. No file editing by hand. About 5 minutes.

What you need

  • A Windows PC or a Mac with ClipForge 1.9.0 or newer. (Claude cannot edit on the phone.)
  • Claude Desktop (the Claude app for Windows or Mac) and, if you use it, Claude Code.
  • From the ClipForge build page (where you download the app), two small files:
    • ClipForge-…-claude-windows.mcpb (Mac: …-claude-macos.mcpb) — the ClipForge extension for Claude Desktop.
    • ClipForge-…-claude-skill.zip — the skill that teaches Claude how to edit your videos well.
  • FFmpeg, a free program Claude's helper uses to read and export videos. Install it once: 
    winget install ffmpeg
    Windows: open Terminal from the Start menu, paste, press Enter. Mac: open Terminal and use brew install ffmpeg instead (needs Homebrew from brew.sh).

AClaude Desktop: install the extension

  1. Download the .mcpb file for your computer from the ClipForge build page. Leave it as it is (do not unzip or rename it).
  2. Double-click the file. Claude opens and shows ClipForge with an Install button. Click Install.
    Nothing happens when I double-click

    Open Claude, then Settings → Extensions. (In the newer layout: Settings → Desktop app → Manage next to Extensions.) Click Advanced settings, find Extension Developer, click Install Extension… and choose the .mcpb file.

    Names checked against Claude's help pages on 17 Nov 2026; the wording may differ a little in your version.

  3. Remove the old hand-made entry, so Claude does not get ClipForge twice (see just below). Skip this if you never edited the config file.
  4. Restart Claude completely. Windows: right-click the Claude icon near the clock → Quit, then start it again. Mac: Cmd+Q, then start it again.

Removing the old entry (only if you added one by hand before)

In Claude: Settings → Developer → Edit Config. A folder opens with claude_desktop_config.json selected. Open it with Notepad (Mac: TextEdit).

Delete the marked lines — the "clipforge" part, from its name to its closing }:

{
  "mcpServers": {
    "clipforge": {      "command": "C:\\Users\\<you>\\ClipForge\\clipforge-mcp.exe"    }  }
}

So that it ends up like this:

{
  "mcpServers": {}
}
  • If the file has other things in it (other names inside "mcpServers", or a "preferences" part), keep them. Remove only the "clipforge": { … } block and the comma right before or after it, so that no comma is left dangling before a }.
  • Save the file, then restart Claude (step 4 above).
  • Not sure? Paste the file's text to Claude and ask: "Remove the clipforge entry from this config and give me the whole file back."

If the Mac blocks it

The helper inside the extension is not signed by an identified Apple developer. If Claude says the ClipForge extension could not start, or macOS shows "cannot be opened", open Terminal, paste this, press Enter, and restart Claude:

xattr -dr com.apple.quarantine ~/Library/Application\ Support/Claude/Claude\ Extensions

The extension is for Macs with Apple chips (M1 and newer). If it still does not start, use the manual way at the bottom of this page with the ClipForge-Claude folder from the Mac download. (Not yet tried on a real Mac: please tell Claude what you saw.)

When a new ClipForge build comes out

Download the new .mcpb and install it the same way; it replaces the old one. Extensions installed from a file do not update by themselves.

BAdd the ClipForge skill

The skill is a short guide for Claude: check the connection first, show you a plan before big changes, offer a safety copy, how to clean up a podcast, make a family video, a slow-motion highlight, an upright version, or shorts from a long video.

  1. Download ClipForge-…-claude-skill.zip from the build page. Do not unzip it.
  2. In Claude (the app or claude.ai), open Customize (in the side bar on the left) → Skills.
  3. Click Upload a skill and choose the zip file.
  4. Make sure clipforge-editing is switched on in the list.

Menu names checked against Claude's help pages on 17 Nov 2026 (older versions: Settings → Capabilities → Skills). The wording may differ in your version. If there is no upload button, switch on Code execution and file creation under Settings → Capabilities first.

A new ClipForge version may bring a newer skill: remove the old one in the same list and upload the new zip.

CClaude Code: one line

Claude Code does not use the .mcpb file. It starts the helper program that comes inside the ClipForge download: clipforge-mcp.exe in your ClipForge folder (Mac: the ClipForge-Claude folder).

Windows — open Terminal and run this, with your ClipForge folder (in File Explorer, right-click clipforge-mcp.exe → Copy as path gives you the part in quotes):

claude mcp add --scope user clipforge -- "C:\Users\<you>\ClipForge\clipforge-mcp.exe"

Mac — after dragging ClipForge-Claude into Applications:

claude mcp add --scope user clipforge -- /Applications/ClipForge-Claude/clipforge-mcp
  • It answers with a line starting with Added. To look: claude mcp list. To take it away again: claude mcp remove clipforge.
  • --scope user makes ClipForge available in every folder you start Claude Code in.
  • If you unzip a newer ClipForge into a different folder, remove and add it again with the new place.
  • The skill in Claude Code: when you are signed in to Claude Code with the same Claude account, the skill from step B loads by itself (recent Claude Code versions). Or unzip the skill zip into the folder .claude\skills in your user folder, so that you get C:\Users\<you>\.claude\skills\clipforge-editing\SKILL.md (Mac: ~/.claude/skills/clipforge-editing/SKILL.md).
  • Keep Claude Code open while a long export runs: on Windows, closing it can stop the export.

DCheck that it works

Start a new chat and ask:

What version of ClipForge are you connected to?

Claude should answer with a line like ClipForge 1.9.0 (build 32) · 17 Nov 2026, 04:51 UTC · 097beac, the folder your projects are in, and whether FFmpeg was found. Compare the version with Help → About ClipForge in the app: they should match.

Then try:

List my ClipForge projects.

The first time, Claude asks whether it may use the ClipForge tools: allow it. On a Mac, macOS may ask whether Claude may use your Documents folder: allow it, the projects are there.

One rule: before Claude changes a project, go back to ClipForge's project list (or close ClipForge). Open the project again afterwards to see the result. If you forget, Claude tells you; nothing breaks.

The manual way (fallback, if the extension cannot be installed)

This is what the extension does for you. In Claude: Settings → Developer → Edit Config, open claude_desktop_config.json and make it look like this (Windows: your own folder, with every \ written twice):

{
  "mcpServers": {
    "clipforge": {
      "command": "C:\\Users\\<you>\\ClipForge\\clipforge-mcp.exe"
    }
  }
}

Mac:

{
  "mcpServers": {
    "clipforge": {
      "command": "/Applications/ClipForge-Claude/clipforge-mcp"
    }
  }
}

Save and restart Claude. Use either the extension or this entry, not both. On a Mac, run once in Terminal: xattr -dr com.apple.quarantine /Applications/ClipForge-Claude

More detail: the "Claude control" section of the ClipForge README.

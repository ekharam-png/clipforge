Connect Claude to ClipForge

After this, you can ask Claude in plain words to edit your ClipForge videos on your computer. You do it once: from ClipForge 1.12 on, the app keeps the connection up to date by itself. About 3 minutes.

What you need

  • A Windows PC or a Mac with ClipForge 1.12 or newer, started at least once. (Claude cannot edit on the phone.)
  • Claude Desktop (the Claude app for Windows or Mac) or Claude Code.
  • FFmpeg, a free program Claude's helper uses to read and export videos. Install it once: 
    winget install ffmpeg
    Windows: open Terminal from the Start menu, paste, press Enter. Mac: open Terminal and use brew install ffmpeg instead (needs Homebrew from brew.sh).

Nothing else has to be downloaded: everything Claude needs comes inside ClipForge.

1In ClipForge: Help → Connect to Claude…

Open ClipForge on the computer. In the menu bar choose Help → Connect to Claude….

The page says The Claude helper is installed and shows its version. ClipForge puts this helper into a folder of its own every time it starts, and again after every update:

  • Windows: %LOCALAPPDATA%\ClipForge\claude
  • Mac: ~/Library/Application Support/ClipForge/claude

Claude is pointed at that folder once, in step 2. That is why later updates need nothing from you.

From ClipForge 1.14 the page does the connecting for you. For Claude Desktop and for Claude Code it shows a small light (green: connected) and one button, Connect. Press it, then close Claude and open it again. That is all; steps 2a and 2b below are the other ways, if you prefer them or the button cannot be used.

  • Why close and reopen Claude? Claude reads its list of tools when it starts. It then starts the ClipForge helper itself whenever it needs it. ClipForge does not have to be running, and there is nothing to switch on.
  • Claude Desktop: Connect adds one entry called clipforge to Claude's settings file (also for the Claude from the Microsoft Store). It keeps everything else in that file, makes a dated backup next to it first, and refuses to touch a file it cannot read. Quit Claude from the icon near the clock too, then start it again.
  • Claude Code: Connect runs the claude mcp add line for you. If an older ClipForge connection is there, it lists what it will replace and asks once. Then start a new Claude Code session (/mcp shows the list).
  • Is it running? The page says "In use by Claude Desktop now" while a Claude session has the helper open, and "Not in use right now" otherwise. That is normal: Claude starts it when needed.
  • Test starts the helper by itself and runs its quick self-test. PASS means the helper works, whatever Claude does.
  • Disconnect removes only the clipforge entry again.

Written without a real Claude installation at hand (November 2026): if a light is wrong or Connect does not work on your computer, open Details on the page and tell Claude what it says.

2aClaude Desktop: install the extension

Only if you did not use the Connect button in step 1. Use either the button or the extension, not both (the page tells you when both are there).

  1. On the Connect to Claude page, click Save the Claude extension file… and save it, for example on the desktop. Leave it as it is (do not unzip or rename it).
  2. Double-click the saved file. Claude opens and shows ClipForge with an Install button. Click Install.
    Double-clicking does not open Claude (Windows asks "Select an app to open this .mcpb file")

    That happens with the Claude from the Microsoft Store: it is not registered for this kind of file. Close that window and do this instead (you can also drag the file onto the Extensions page). Open Claude, then Settings → Extensions. (In the newer layout: Settings → Desktop app → Manage next to Extensions.) Click Advanced settings, find Extension Developer, click Install Extension… and choose the saved file.

    Names checked against Claude's help pages on 17 Nov 2026; the wording may differ a little in your version.

  3. Restart Claude completely. Windows: right-click the Claude icon near the clock → Quit, then start it again. Mac: Cmd+Q, then start it again.

The same file is also on the download page (ClipForge-claude-windows.mcpb / ClipForge-claude-macos.mcpb), if you prefer to download it.

If the Mac blocks it

If Claude says the ClipForge extension could not start, or macOS shows "cannot be opened", open Terminal, paste this, press Enter, and restart Claude:

xattr -dr com.apple.quarantine ~/Library/Application\ Support/Claude/Claude\ Extensions

The helper is for Macs with Apple chips (M1 and newer). (Not yet tried on a real Mac: please tell Claude what you saw.)

2bClaude Code: one line

Only if you did not use the Connect button in step 1.

On the Connect to Claude page, click Copy next to the line that starts with claude mcp add, paste it into a terminal and press Enter. It is this line with your own folder filled in:

Windows

claude mcp add --scope user clipforge -- "%LOCALAPPDATA%\ClipForge\claude\clipforge-mcp.exe"

Mac

claude mcp add --scope user clipforge -- "$HOME/Library/Application Support/ClipForge/claude/clipforge-mcp"
  • It answers with a line starting with Added. To look: claude mcp list. To take it away again: claude mcp remove clipforge.
  • --scope user makes ClipForge available in every folder you start Claude Code in.
  • The line in the app has the full path already; the Windows line above works in Command Prompt (PowerShell: use the one from the app).

3Check that it works

Start a new chat and ask:

Run the ClipForge self-test.

Claude makes a small sample video in a temporary folder and tries everything on it: cutting, titles, sound, an export, undo. After less than a minute it shows a list with PASS for each check. Your own projects are not touched.

Or ask:

What version of ClipForge are you connected to?

Claude answers with a line like ClipForge 1.12.0 (build 142) · 18 Nov 2026, 10:00 UTC · 0a1b2c3, which helper it is using, the folder your projects are in, and whether FFmpeg was found. Compare the version with Help → About ClipForge in the app: they should match.

The first time, Claude asks whether it may use the ClipForge tools: allow it. On a Mac, macOS may ask whether Claude may use your Documents folder: allow it, the projects are there.

One rule: before Claude changes a project, go back to ClipForge's project list (or close ClipForge). Open the project again afterwards to see the result. If you forget, Claude tells you; nothing breaks.

After a ClipForge update

Nothing to do. When ClipForge is updated and started, it puts the new helper into its folder. Claude uses it the next time Claude itself is started. The extension stays as it is, and there is nothing to upload.

  • The guide that tells Claude how to edit well now comes from the helper, so it always fits your version.
  • The skill is optional now. If you like, upload ClipForge-claude-skill.zip from the download page once (Claude → Customize → Skills → Upload a skill). It only helps Claude notice when you are talking about ClipForge, and it never needs to be uploaded again. If an older ClipForge skill is in that list, you can leave it or replace it with this one.
  • An export that Claude started keeps running when you close Claude or Claude Code, also on Windows. Ask Claude later how far it is.

If you connected Claude before version 1.12

Do steps 1 to 3 once more: the old connection pointed at a helper inside the old extension or inside the ClipForge folder, which does not exist there any more.

  • Claude Desktop: install the extension from step 2a; it replaces the old one.
  • Claude Code: run claude mcp remove clipforge, then the line from step 2b.
  • If you once edited the config file by hand, remove that entry so Claude does not get ClipForge twice: in Claude, Settings → Developer → Edit Config, open claude_desktop_config.json with Notepad (Mac: TextEdit) and delete the marked lines: 
    {
  "mcpServers": {
    "clipforge": {      "command": "C:\\Users\\<you>\\ClipForge\\clipforge-mcp.exe"    }  }
}
    Keep everything else in the file, and leave no comma dangling before a }. Save, then restart Claude. Not sure? Paste the file's text to Claude and ask: "Remove the clipforge entry from this config and give me the whole file back."

The manual way (fallback, if the extension cannot be installed)

This is what the extension does for you. In Claude: Settings → Developer → Edit Config, open claude_desktop_config.json and make it look like this, with the helper's path from the Connect to Claude page (Windows: every \ written twice):

{
  "mcpServers": {
    "clipforge": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\ClipForge\\claude\\clipforge-mcp.exe"
    }
  }
}

Mac:

{
  "mcpServers": {
    "clipforge": {
      "command": "/Users/<you>/Library/Application Support/ClipForge/claude/clipforge-mcp"
    }
  }
}

Save and restart Claude. Use either the extension or this entry, not both.
